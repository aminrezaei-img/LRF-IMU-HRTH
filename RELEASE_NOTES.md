# Release notes

## 0.1.0 — Milestone 1 — 2026-08-01

This initial public-release boundary adds:

- portable configuration and path primitives;
- six-channel, accelerometer-only, and sensitivity-grid YAML skeletons;
- seven byte-preserved audit/locked-reference files;
- provisional documentation for citation, data access, model scope,
  reproducibility, contribution, security, and licensing decisions; and
- durable empty directories for later scientific migration.

It deliberately does not include scientific source code, raw or preprocessed
data, checkpoints, synthetic caches, generated results, logs, manuscript or
review history, or a `LICENSE` file.

The pinned audit recorded 4,619 `Results/` files totaling 34,791,553,468 bytes.
The current immutable source state was separately observed at 4,667 files and
34,811,675,494 bytes, including 48 later website-trajectory JSON files and four
rewritten flow-trajectory images. Those differences are documented, excluded,
and not copied.
