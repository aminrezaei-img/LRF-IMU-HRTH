# Code of Conduct

This Milestone 1 document is a provisional community standard, not a complete
institutional policy.

Participants are expected to be respectful, constructive, clear about evidence,
and careful not to disclose REALDISP data, participant-derived artifacts,
credentials, or private review material. Harassment, discrimination,
intimidation, deliberate disclosure of private material, and knowingly
misrepresenting reproduction evidence are not acceptable.

If a concern arises, do not post sensitive details publicly. Contact the
repository maintainers through the project's established private channel once
one is provided, or use the hosting service's private reporting mechanism. A
future release should replace this placeholder process with a maintainer and
response contact that has been reviewed by the project owners.
