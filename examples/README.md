# Small examples

These files are sanitized interface examples. They contain no participant
data, checkpoints, generated arrays, or machine-specific paths.

- `example_generation_config.yaml` shows the inputs for one decoded HARTH
  window.
- `example_mapping_input.json` shows a resolved interval with contextual hint
  evidence.
- `example_physical_state_mapping.csv` shows the mapping output shape.
- `example_interval_manifest.json` shows the provenance fields expected from a
  generated interval.

Use the canonical commands in the root [README](../README.md) with local paths
to the data and checkpoint files.
