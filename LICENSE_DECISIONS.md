# License decisions

## Milestone 1 status

This is a provisional decision record, not a license grant. No `LICENSE` file
is included in Milestone 1.

The audit did not establish all inputs needed for a responsible license
decision: provenance and compatibility of future migrated code, dependency
licenses, REALDISP access terms, and institutional or publisher requirements
still need review. The absence of a `LICENSE` file means that reuse rights have
not been clarified by this repository.

## Current boundaries

- The seven locked audit/reference files are preserved for provenance; their
  presence does not grant permission to reuse the underlying dataset, results,
  or source project.
- REALDISP data and participant-derived artifacts are not redistributed.
- Checkpoints, synthetic caches, generated results, manuscript history, and
  review material are not part of this release.
- The package metadata and configuration layer should not be treated as a final
  licensing decision for scientific code that may be migrated later.

## Before a later release

Confirm the dataset's current terms, audit all copied and newly migrated code,
record third-party attributions, resolve institutional requirements, and choose
a license that covers the actual public contents. Add a `LICENSE` file only
after that review is complete.
