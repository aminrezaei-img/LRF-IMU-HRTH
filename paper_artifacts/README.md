# Paper artifacts

No manuscript, publisher proof, figure package, result table, checkpoint, or
generated participant-derived artifact is included in Milestone 1.

This directory is a durable placeholder for later, separately reviewed paper
artifacts. A future addition must have established provenance, privacy and
rights review, a clear source-to-paper mapping, and a reproducible hash or
manifest. The audit records several unresolved figure and table provenance
questions; this placeholder does not resolve them.
